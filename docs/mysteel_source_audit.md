## 结论摘要

Mysteel 官方站内确实存在一批比普通日报更值得用于短期校准的内容。优先级最高的不是观点文章，而是以下四组“可结构化的新事实”：

1. 突发事件：煤矿停复产、安监、钢厂检修复产、环保限产、事故、天气和运输中断。Mysteel 移动首页按分钟更新并展示“快讯”入口，官方样例曾在 11:59 发布“长治沁源县预计新增复产一座煤矿”；但该综合流混杂宏观、价格复盘和转载信息，必须按事件关键词、影响产能和首次披露进行过滤。[Mysteel 移动首页](https://m.mysteel.com/)
2. 高频产业数据：铁矿发运/到港、焦煤矿山与洗煤厂生产、独立焦企与钢厂煤焦生产、建筑钢材成交量、建筑钢材库存及电弧炉开工。这些栏目有相对固定的周度或日度发布时间，适合计算预期差。[铁矿石运量分析](https://tks.mysteel.com/datas/article/pa6242aaaaaa1.html)、[煤炭调研数据聚合页](https://coal.mysteel.com/article/p-5153%2C5166%2C5167%2C5168-------------1.htm)、[建筑钢材品种库存](https://jiancai.mysteel.com/article/pa4860a010101aaaaa1.html)
3. 可执行价格事件：焦炭提涨/提降的“发起、钢厂回应、落地、执行时间”以及主流钢厂建筑钢材出厂价调整。前者对焦炭、焦煤和铁矿的传导价值较高；后者常是现货行情的反应，只有大钢厂旬价、结算价或超预期调价才值得高权重。[煤焦热点页](https://coal.mysteel.com/article/pa5151%2C4415aaaaaa1.html)、[钢厂频道](https://factory.mysteel.com/)
4. 交易验证数据：全国建筑钢材成交量、铁矿港口现货成交笔数、焦煤竞拍成交量和流拍率。它们适合验证需求和市场情绪，但明显受当日期货价格反向影响，不能直接当作独立利多/利空。[全国建筑钢材成交量页面](https://www.mysteel.com/hot/265617.html)、[铁矿石成交汇总](https://tks.mysteel.com/jkk/article/pa5743%2C5744aaaaaa1.html)、[炼焦煤栏目](https://coal.mysteel.com/article/pa5150a050202aaaaa1.html)

当前项目的主要问题不仅是“漏配栏目”，还包括“配置存在但没有进入校准”和“实际入库与 source_id 含义错位”：

- 校准检索不再按栏目等级筛选；17 个必要栏目统一进入同一时间对齐层，再按可用时间、事件类型、重复事件和价格复述标记处理。
- 2026-08-18 本地数据库共有 392 条文章，但只有 `rebar_daily`、`rebar_weekly`、`iron_daily`、`iron_port_stock`、`iron_pigiron_output` 五个 `source_id`；煤焦为 0 条，`iron_steelmill_stock` 也为 0 条。
- 宽泛列表发生内容串入：`iron_daily` 和 `iron_pigiron_output` 中出现了高炉检修、澳巴发运等不同事件类型。由此可见，不能依赖 `source_id/report_type` 判断资讯含义，必须从标题和正文提取 `event_type`。

## 审计方法与限制

- 只使用 `mysteel.com` 及其官方子域页面，不用媒体转载或第三方整理。
- “发布时间/频率”仅在官方列表页连续样例或官方文章时间能够确认时填写；其余明确标记“无法确认”。
- 若 Mysteel 页面转载矿企、政府或媒体消息，本报告仍把它视为 Mysteel 官方页面中的线索，但不把它等同于 Mysteel 独家调研。模型应额外记录 `origin_source` 和 `is_reprint`。
- 若干 `sources.yaml` 中的栏目直链对普通抓取返回 411 或无法安全打开，因此只能核验官方搜索可见的栏目页/文章页。此类项目的固定发布时间、分页稳定性和免登录抓取可行性均标为“无法确认”，不作推断。
- 研究建议中的 P0/P1/P2/P3 仅表示后续工程优先顺序，不是运行时过滤字段，也不会进入数据库或校准查询。

## 与 `sources.yaml` 的覆盖对照

### 当前 17 个必要栏目

| source_id | 配置内容 | 审计判断 |
|---|---|---|
| `rebar_daily` | 建筑钢材日报 | 价格复盘比例高，由 `price_echo` 标记并降权。 |
| `rebar_inventory` | 建筑钢材库存/产量数据 | 只从首次发布时间开始可用，统计期不能替代发布时间。 |
| `iron_daily` | 铁矿石日报 | 宽泛内容按 `event_type` 重分类，价格复述不重复计价。 |
| `iron_port_stock` | 铁矿港口库存 | 首次发布时间决定可用时间。 |
| `iron_pigiron_output` | 高炉/铁水数据 | 只从发布后影响尚未完成的端点。 |
| `iron_steelmill_stock` | 钢厂铁矿库存 | 统计期较早也不能提前可用。 |
| `coal_price_index_daily` | 煤焦价格指数日报 | 日报默认标记 `price_echo`。 |
| `coal_surveys` | 煤焦生产调查 | 统计期和发布时间分开存储。 |

### 运行时处理

所有必要栏目都会先进入查询结果，再由 `zixun.time_alignment` 计算
`available_at`、有效年龄、可影响的真实收盘端点、`event_type`、`price_echo` 和
结论延迟。是否对数值产生影响由这些字段和历史研究配置决定，不再由栏目等级决定。

### 完全遗漏或缺少独立稳定 source_id

1. 综合快讯流中的政策、事故、天气、运输、停复产事件。
2. 钢厂频道的建筑钢材检修复产、重要钢厂旬价/结算价。
3. 铁矿石澳巴/全球发运和中国到港量；当前只是宽泛栏目偶然串入，不能视为稳定覆盖。
4. 铁矿石港口现货成交一览。
5. 建筑钢材独立电弧炉生产调查。
6. 焦煤竞拍挂牌/成交/流拍率。
7. 523家焦煤矿山、314家洗煤厂生产调查。
8. 独立焦企生产调查以及与247家钢厂煤焦调查的明确拆分。
9. 山西煤矿停复产连续追踪。
10. 早读/晚餐的政策事件路由（只作路由，不直接作数值观点）。

## 建议接入顺序

### 第一阶段：先修复现有核心数据链

1. 修复煤焦数据源的抓取，使港口库存、煤焦指数、钢厂煤焦生产真正入库。
2. 为入库文章增加内容级 `event_type`，不要再用 `source_id/report_type` 代替事件类型。
3. 将螺纹钢库存/生产调查保持为独立数值栏目，解决配置 URL 与已核验官方列表不一致的问题。
4. 给每个事件记录 `publish_time`、`available_at`、`observation_start/end`、`actual/previous`、样本口径和首次披露 URL。

### 第二阶段：增加最有增量的数据源

1. 铁矿发运、铁矿到港。
2. 焦煤矿山、洗煤厂、独立焦企生产调查。
3. 焦煤竞拍流拍率和焦炭提涨/提降状态机。
4. 建筑钢材成交量和电弧炉生产调查。

### 第三阶段：增加事件快讯，但严格限流

从综合快讯、钢厂动态、矿山动态中只接入以下事件：

- 已确认发生的事故、停产、复产、检修、环保限产；
- 港口、铁路、公路和口岸中断或恢复；
- 四大矿山产量/发运指引变化；
- 钢铁、煤矿、进口和地产基建相关政策正式发布；
- 可量化的影响产能、日产量、持续时间或价格执行幅度。

其余观点、价格复盘、长期项目、融资、ESG和普通企业新闻不进入数值校准。

## 校准使用规则

建议把资讯权重写成：

```text
有效冲击 = 历史事件效应
         × 相关性
         × 新颖度
         × 影响规模
         × 来源/口径可靠度
         × 时间衰减
         × 未被预测起点前价格吸收比例
```

必须额外执行四条约束：

1. 同一统计期或同一轮提涨/提降只建立一个事件，多篇文章只更新状态和证据，不重复加权。
2. 价格复盘、期货先行导致的成交变化、早读中的夜盘涨跌均标记 `price_echo=true`，数值校准权重接近0。
3. 没有前值、季节性预期或历史分位的数据，不根据“增/减”方向机械交易。
4. 抓取不到正文、发布时间或统计口径无法确认时默认 `abstain`，不能由标题补全未知事实。

## 最终优先级清单

| 优先级 | 应采取的动作 |
|---|---|
| P0 | 修复煤焦数据入库；接入焦煤矿山/洗煤厂、独立焦企、铁矿发运/到港；结构化焦炭提涨提降、螺纹库存/生产/成交；建立快讯事件预筛。 |
| P1 | 接入钢厂检修复产、铁矿矿山重大动态、进口煤口岸异常、电弧炉调查、大钢厂旬价/结算价。 |
| P2 | 铁矿港口成交、普通钢厂日调价、早读/晚餐、普通进口煤和区域行情，仅作确认或事件路由。 |
| P3 | 月报、长期项目进展、融资/ESG、编辑观点和纯价格复盘，不用于短期数值校准。 |

总体判断：Mysteel 有足够多的短期增量信息，但真正值得交易的是“首次披露、可量化、尚未被盘面吸收”的事件和数据。当前项目最迫切的工作是恢复煤焦数据、拆分事件类型和接入发运/到港/竞拍/停复产，而不是继续扩大日报与观点文章数量。
